# 获取公开作品详情

按语义化 `slug` 或 32 位 `uuid` 获取单个已发布作品的完整信息，同时返回上下相邻的已发布作品（用于详情页翻页）。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `GET` |
| 路径 | `/api/v1/works/:slugOrUuid` |
| 鉴权 | 无需鉴权 |
| 成功状态码 | `200` |

## 路径参数

- `slugOrUuid`：作品 `slug`（小写字母、数字、连字符）或 32 位 `uuid`。

## 响应字段

- `work`：当前作品完整数据。
- `prevWork`：上一件已发布作品。
- `nextWork`：下一件已发布作品。

## 常见错误码

- `1009`（HTTP 404）：作品不存在或未发布。
