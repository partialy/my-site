# 删除白名单规则

按规则 ID 删除白名单规则。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `DELETE` |
| 路径 | `/api/v1/admin/system-config/whitelist/:id` |
| 鉴权 | 管理员 JWT |
| 操作审计 | 记录 |
| 成功状态码 | `200` |

## 路径参数

| 参数 | 说明 |
| :--- | :--- |
| `id` | 白名单规则 ID |

## 响应示例

```json
{
  "code": 0,
  "msg": "白名单规则已删除",
  "data": null,
  "success": true
}
```

## 常见错误码

- `1009`（HTTP 404）：白名单规则不存在。
