# 批量永久删除文件

按文件 UUID 列表批量永久删除文件记录及其底层存储（本地磁盘或七牛云）。逐个执行引用保护检查：若部分文件正在被站点图标、登录背景、作品封面、轮盘图标或 OG 图引用，系统将跳过受保护文件并继续删除其余可删文件，在响应中返回成功删除清单与跳过原因。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `POST` |
| 路径 | `/api/v1/admin/files/batch-delete` |
| 鉴权 | 管理员 JWT |
| 操作审计 | 记录 |
| 请求类型 | `application/json` |
| 成功状态码 | `200` |

## 请求体（JSON）

| 字段 | 类型 | 必填 | 约束 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `ids` | `string[]` | 是 | `1~100` 项，每项为标准 UUID | 待永久删除的文件 ID 列表 |

## 响应结构（`data`）

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `deletedCount` | `number` | 实际成功永久删除的文件数 |
| `deletedIds` | `string[]` | 成功删除的文件 UUID 列表 |
| `failed` | `Array<{ id, name, reason }>` | 因被引用、不存在或云端删除异常而跳过的文件及原因 |
