# 删除普通配置

按配置键删除普通动态配置并刷新缓存。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `DELETE` |
| 路径 | `/api/v1/admin/configs/:key` |
| 鉴权 | 管理员 JWT |
| 操作审计 | 记录 |
| 成功状态码 | `200` |

## 路径参数

| 参数 | 说明 |
| :--- | :--- |
| `key` | 配置键（需 URL 编码） |

## 响应示例

```json
{
  "code": 0,
  "msg": "配置已删除",
  "data": null,
  "success": true
}
```

## 常见错误码

- `1009`（HTTP 404）：配置不存在。
