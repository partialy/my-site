# 上报页面访问

前台页面首次加载时上报访问信息；服务端以 `(visitor_id, visit_day)` 唯一约束按 UTC 日尽力去重。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `POST` |
| 路径 | `/api/v1/visits` |
| 鉴权 | 无需鉴权 |
| 限流 | 每分钟最多 60 次（按 IP） |
| 成功状态码 | `201`（当日首次记入） / `200`（当日重复上报） |

## 请求体（JSON）

| 字段 | 类型 | 必填 | 校验规则 |
| :--- | :--- | :--- | :--- |
| `visitorId` | `string` | 是 | 标准 UUID（浏览器持久化存储） |
| `path` | `string` | 是 | 1–500 位，须为站内绝对路径（`/` 开头，不含 `?`、`#`、`\`） |
| `pageTitle` | `string` | 否 | 最多 150 字符 |
| `referrer` | `string` | 否 | 完整 URL（最多 1000 字符），服务端仅保存其 `origin` |

## 响应示例

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "recorded": true,
    "day": "2026-10-20"
  },
  "success": true
}
```
