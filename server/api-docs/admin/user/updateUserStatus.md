# 禁用或启用业务用户

修改指定业务用户的启用状态；修改状态时递增 `token_version`，使该用户已有 JWT 立即失效。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `PUT` |
| 路径 | `/api/v1/admin/users/:id/status` |
| 鉴权 | 管理员 JWT |
| 操作审计 | 记录 |
| 成功状态码 | `200` |

## 路径参数与请求体

- 路径参数 `id`：用户 `uuid`（32 位无连字符）
- 请求体 JSON：`{ "status": "active" | "disabled" }`

## 响应示例

返回更新后的 `UserSummary` 对象（`msg: "用户已禁用"` 或 `"用户已启用"`）。
