# 服务就绪探针

供网关、容器编排或监控系统检查服务及 SQLite 数据库连通状态（位于 `/api/v1` 前缀之外，不包裹统一 JSON 响应结构）。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `GET` |
| 路径 | `/health` |
| 鉴权 | 无需鉴权 |
| 成功状态码 | `200`（正常） / `503`（数据库不可用） |

## 响应示例

正常（HTTP 200）：
```json
{
  "status": "ok"
}
```

异常（HTTP 503）：
```json
{
  "status": "unavailable"
}
```
