# 读取文件内容

公开读取文件库中的文件内容；本地文件返回二进制流，七牛云文件 `302` 重定向到配置域名直链。已归档文件的历史链接仍可访问。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `GET` |
| 路径 | `/api/v1/files/:id/content` |
| 鉴权 | 无需鉴权 |
| 响应类型 | 二进制文件流或 `302` 重定向 |
| 成功状态码 | `200` / `302` |

## 路径参数

- `id`：文件 UUID（带连字符标准 UUID）

## 常见错误码

- `1009`（HTTP 404）：文件不存在或本地文件丢失。
