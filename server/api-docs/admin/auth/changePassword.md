# 修改管理员密码

修改当前管理员登录密码；修改成功后递增 `token_version`，使现有管理员 JWT 立即失效。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `PUT` |
| 路径 | `/api/v1/admin/auth/password` |
| 鉴权 | 管理员 JWT |
| 操作审计 | 记录（脱敏，不记密码） |
| 成功状态码 | `200` |

## 请求体（JSON）

| 字段 | 类型 | 必填 | 校验规则 |
| :--- | :--- | :--- | :--- |
| `oldPassword` | `string` | 是 | 非空 |
| `newPassword` | `string` | 是 | 8–128 位，且不能与 `oldPassword` 相同 |

## 响应示例

```json
{
  "code": 0,
  "msg": "密码修改成功，请重新登录",
  "data": null,
  "success": true
}
```

## 常见错误码

- `1008`（HTTP 400）：原密码错误。
- `1001`（HTTP 400）：新密码与原密码相同或长度不合法。
