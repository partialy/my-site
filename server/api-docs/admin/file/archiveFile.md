# 归档文件

软删除（归档）指定可用文件；归档后不再出现在文件选择器中，但已有访问链接仍可正常读取。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `DELETE` |
| 路径 | `/api/v1/admin/files/:id` |
| 鉴权 | 管理员 JWT |
| 操作审计 | 记录 |
| 成功状态码 | `200` |

## 路径参数

- `id`：文件 UUID（带连字符标准 UUID）

## 响应示例

```json
{
  "code": 0,
  "msg": "文件已归档",
  "data": null,
  "success": true
}
```
