# 永久删除文件

同时删除文件库记录与底层存储文件（本地文件或七牛对象），原链接立即失效。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `DELETE` |
| 路径 | `/api/v1/admin/files/:id/permanent` |
| 鉴权 | 管理员 JWT |
| 操作审计 | 记录 |
| 成功状态码 | `200` |

## 路径参数

- `id`：文件 UUID（含已归档记录）

## 响应示例

```json
{
  "code": 0,
  "msg": "文件已永久删除",
  "data": null,
  "success": true
}
```

## 常见错误码

- `1014`（HTTP 409）：该文件正被后台/前台站点图标或登录背景引用，禁止删除。
- `1009`（HTTP 404）：文件不存在。
