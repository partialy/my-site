# 查看业务用户详情

按用户 UUID 获取单个业务用户摘要信息。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `GET` |
| 路径 | `/api/v1/admin/users/:id` |
| 鉴权 | 管理员 JWT |
| 成功状态码 | `200` |

## 路径参数

| 参数 | 说明 |
| :--- | :--- |
| `id` | 用户 `uuid`（32 位小写无连字符十六进制） |

## 响应示例

返回 `UserSummary` 对象（结构同 [getUserList.md](getUserList.md) 列表项）。

## 常见错误码

- `1009`（HTTP 404）：用户不存在。
