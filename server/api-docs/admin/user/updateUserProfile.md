# 编辑业务用户资料

按用户 UUID 更新业务用户的昵称和头像访问 URL，不修改账号及密码。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `PUT` |
| 路径 | `/api/v1/admin/users/:id/profile` |
| 鉴权 | 管理员 JWT |
| 操作审计 | 记录 |
| 成功状态码 | `200` |

## 路径参数

| 参数 | 说明 |
| :--- | :--- |
| `id` | 用户 `uuid`（32 位无连字符） |

## 请求体（JSON）

| 字段 | 类型 | 必填 | 校验规则 |
| :--- | :--- | :--- | :--- |
| `nickname` | `string` | 是 | 1–50 位 |
| `avatar` | `string \| null` | 是 | 完整 HTTP(S) URL（最多 2048 字符），传 `null` 表示移除头像 |

## 响应示例

返回更新后的 `UserSummary` 对象（`msg: "用户资料已更新"`）。
