# 修改字典类型

按类型 UUID 修改名称、备注、公开性与启用状态（不修改 `code`）。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `PUT` |
| 路径 | `/api/v1/admin/dictionaries/:id` |
| 鉴权 | 管理员 JWT |
| 操作审计 | 记录 |
| 成功状态码 | `200` |

## 路径参数

| 参数 | 说明 |
| :--- | :--- |
| `id` | 字典类型 `uuid`（32 位小写无连字符十六进制） |

## 请求体（JSON）

| 字段 | 类型 | 必填 | 校验规则 |
| :--- | :--- | :--- | :--- |
| `name` | `string` | 是 | 1–100 位 |
| `remark` | `string` | 是 | 最多 500 位 |
| `isPublic` | `boolean` | 是 | 是否公开 |
| `enabled` | `boolean` | 是 | 是否启用 |

## 响应示例

返回更新后的完整 `DictionaryType` 对象（`msg: "字典类型已更新"`）。

## 常见错误码

- `1009`（HTTP 404）：字典类型不存在。
