# 登记七牛直传文件

当文件直传七牛云完成后，调用本接口由服务端向七牛核对文件大小与 MIME 类型并写入 `file` 表。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `POST` |
| 路径 | `/api/v1/uploads/complete` |
| 鉴权 | 无需鉴权（公开接口） |
| 限流 | 每分钟最多 20 次（按 IP） |
| 成功状态码 | `201` |

## 请求体（JSON）

| 字段 | 类型 | 必填 | 校验规则 |
| :--- | :--- | :--- | :--- |
| `id` | `string` | 是 | 标准 UUID（来自 `prepare` 返回） |
| `key` | `string` | 是 | 1–500 位，须以 `/${id}<ext>` 结尾且不含 `..`（来自 `prepare` 返回） |
| `name` | `string` | 是 | 1–255 位 |
| `mimeType` | `string` | 是 | 支持的文件 MIME |
| `size` | `number` | 是 | 整数 `1–10485760`，须与七牛云对象实际大小一致 |

## 响应示例

返回登记后的 `FileItem`（`url` 为配置的七牛访问域名直链，`msg: "文件已上传"`）。
