# 获取个人主页与关于页配置

公开读取个人主页的站点信息、页脚版权备案与作者档案、创作原则及已发布作品总数。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `GET` |
| 路径 | `/api/v1/portfolio/profile` |
| 鉴权 | 无需鉴权 |
| 成功状态码 | `200` |

## 响应字段

- `site`：站点名称、标题、SEO 描述、关键词、规范 URL 与 OG 图片。
- `footer`：版权年份、所有者、域名、ICP 备案号及链接。
- `about`：作者名、头衔、所在地、邮箱、简介、`principles` 三条创作原则及 `worksCount`（已发布作品数）。
