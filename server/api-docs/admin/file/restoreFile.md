# 恢复归档文件

恢复已归档文件为可用状态，使其重新出现在文件选择器中。

## 基本信息

| 属性 | 说明 |
| :--- | :--- |
| 方法 | `PUT` |
| 路径 | `/api/v1/admin/files/:id/restore` |
| 鉴权 | 管理员 JWT |
| 操作审计 | 记录 |
| 成功状态码 | `200` |

## 路径参数

- `id`：文件 UUID（带连字符标准 UUID）

## 响应示例

```json
{
  "code": 0,
  "msg": "文件已恢复",
  "data": null,
  "success": true
}
```
